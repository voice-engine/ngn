# CALIB.md — 线阵 4 麦「通道 → 物理位置」标定指南

遗留问题（LIVE_REPORT）：通道-物理位置映射未确证，通道重排曾使 DOA 从
7.9° 漂到 41.3°。本工具用**能量包络峰值排序**在线标定通道顺序，给出
`--mic-map` 建议文案。

- 工具：`tools/calib_mic_order.py`（纯 stdlib，板上直接跑）
- 一键脚本：`tools/calib_mic_order.sh`（板上：录音 + 分析）
- 输入：**原始采集路径** 4ch16k WAV（`~/ac108/mic4-record16.sh`，通道N=物理麦N）。
  不要用 `arecord -D voice_mic*`——那是引擎输出单声道，无通道信息。

## 原理

声源最靠近某麦时，该麦通道能量包络达到峰值。声源沿线阵走一趟，4 个通道
的包络峰值时刻按物理次序单调出现 → 按峰值时刻排序 = 通道的空间次序。
全程只用幅度（不用相位），对室内反射、窄带噪声比互相关法更鲁棒。

## 操作步骤（走线法，推荐）

1. 板上执行：`~/voice/tools/calib_mic_order.sh 12`
2. 看到 `>>> 现在开始走 <<<` 提示后：
   - 站到线阵**一端**外侧 30~50cm（沿阵列法线，即垂直于四个麦连线的方向）
   - **持续出声**（大声数数 1-2-3-4 循环即可），以 ~0.3 m/s 慢速匀速走到另一端
   - 12 秒内走完全程（4 麦阵列典型长度 12cm——太短，走线法信噪分离有限时改用法 2）
3. 读输出：
   - `位置p ← chN` 表 + `建议引擎参数文案: --mic-map a,b,c,d`
   - **位置 0 = 走线起点端**；想以另一端为位置 0 就用输出里给的反转顺序

## 操作步骤（法 2：依次凑近，短阵列更稳）

依次凑近每个麦（嘴距麦 5~10cm）说 1~2 秒再换下一个，顺序随意但记住
物理顺序；分析同上（峰值时刻排序 = 凑近顺序）。适合 4cm 麦间距的短线阵。

## 阈值与不确定度判定

| 参数 | 默认 | 含义 |
|---|---|---|
| `--snr-db` | 15 | 每通道包络峰对噪声底（10 分位 RMS）的信噪比门槛；不足 → 拒绝下结论 |
| `--min-sep-win` | 3 | 相邻通道峰值时刻最小间隔（默认 3 窗 = 60ms）；不足 → 判为固定点声源 |
| `--win-ms/--hop-ms` | 40/20 | 包络窗/步进 |
| `--smooth-win` | 5 | 包络滑动平均（窗） |

任一门槛不过 → 输出「不确定度不足请人工放源」类提示并 exit 2（**不出映射**）。
环境音/桌面底噪跑冒烟即应落在该分支——这是预期行为，不是工具故障。

## 判定可信的标志

- 4 通道峰 SNR 均 ≥15dB（安静房间正常说话 ≈ 25~40dB）
- 峰值时刻间隔与走线节奏一致（每麦 ≥0.5s）
- 用给出的 `--mic-map` 跑引擎，对已知方向声源 `doa_latest` 与真值一致（±10°）

## 注意

- `--mic-map` 为**建议文案**：引擎当前版本尚未实现该参数（映射生效需引擎
  侧支持，见 ENGINE_REPORT 待办）；先以本工具结论修正 DOA 解读与 BF 通道序。
- 走线起点决定位置 0 朝向；DOA 角度参考系（哪端为 0°/90°）需与引擎
  `va_doa_bf_create(..., "ula", 0.04)` 的约定对齐后统一。
